0.1.0 · 首个测试版

  • 形态：把上游纯静态站打包为飞牛 fnOS 本地应用。由 app/ui/index.cgi 静态分发， 无服务端、不监听端口、无常驻进程、不申请开放 API 权限、不访问 NAS 文件。
  • 路径适配：站点挂在 CGI 子路径下，补齐 .json / .webmanifest 等 MIME 类型与缓存头，拒绝目录穿越。
  • 禁用 PWA：移除 pwa.js / sw.js / manifest.webmanifest 的引用（NAS 局域网 HTTP 下 Service Worker 不生效，留着只会拿到旧缓存）。
  • 移除商业与第三方元素：删除 goods/ 商品推广页、知识点索引 kp/ 入口、首页第三方智商测试卡片、诊断页第三方搜索导流、分享图二维码外链； 清空 Cloudflare 信标与上游统计端点。产物在关闭统计时零外部请求。
  • 统计（独立可插拔，默认关闭）：新增 assets/stats-config.js 适配层， 接管上游事件钩子但禁用其原始上报。只有用户在本页主动开启后才发 install / open / update 三类匿名事件； 不采集答题内容、孩子档案、错题数据或任何可识别个人信息。可随时一键关闭。
  • 署名与合规页：新增 ABOUT-NAS.html（原作者署名、原仓库链接、 原在线站点链接、CC BY-NC 4.0 许可全文、改编声明、改动清单、内容免责、统计开关）， 随包附 LICENSE-upstream.txt 全文；assets/vendor/ 下各 MIT 许可原样保留。
  • 安装向导：新增数据来源、许可、内容免责与统计默认关闭的告知，需勾选同意后安装。
  • 未改动：上游图谱数据、题库、诊断逻辑、页面样式与前端交互代码均未修改。

0.1.0.10 · 测试迭代

  • 修复匿名统计上报通路：跨域信标（sendBeacon）的 JSON 请求会被浏览器 静默丢弃（实测返回成功但数据实际不发），导致开启统计后仍然零上报；现改为 fetch 上报 （同端点、同载荷、同三类匿名事件，机制不变）。另补 http 访问下的同规则哈希兜底， http / https 两种访问方式均可正常上报。

0.1.0.8 · 测试迭代

  • 精简桌面入口为唯一图标：移除「中小学知识图谱（完整版）」重复入口—— 0.1.0.5 排查桌面图标问题期间曾同时注册两个入口（iframe 型与 url 型，指向同一页面）， 病灶修复后二者均为冗余，且各渲染一个桌面图标。现仅保留单一入口，桌面只显示一个图标。

0.1.0.7 · 测试迭代

  • 修复桌面图标缺失与打开无反应（根因修复）：真机取证确认入口注册始终正常， 病灶在 manifest 的 ctl_stop=false——它使应用被系统注册为「不可启动」类型 （与 python / node 运行时包同型），安装后状态停留在 nostart，而桌面会整体过滤 nostart 状态的入口，图标因此不出现、点击无反应。现改为 ctl_stop=true， 安装后状态进入 running，桌面图标与打开行为恢复正常。
  • 移除无效的补链接逻辑：0.1.0.6 在应用目录根补 ui / www 符号链接的方案实测无效（安装脚本无该目录写权限，链接从未建成；桌面与入口也不依赖该路径）， 本版移除该逻辑，安装布局自诊断日志保留。

0.1.0.6 · 测试迭代

  • 修复桌面图标缺失与打开失败（0.1.0.5 真机诊断定位到桌面入口读取位置）： 桌面入口按「应用目录 ui/config」读取，而应用文件安装在 target/ 内； 现安装时在应用目录根补 ui / www 链接指向 target/ 内同名目录， 桌面与应用卡片即可发现入口。静态分发自 0.1.0.5 起正常（浏览器可直接访问）。 （该方案后经 0.1.0.7 真机取证证实无效：链接因权限从未建成，桌面问题另有根因，见 0.1.0.7。）
